# Data backlog — moved

**This file is now a pointer. The backlog lives in [`backlog.md`](./backlog.md).**

Consolidated 2026-09-03, because six separate lists meant reading six files to
answer "what is left?", and none of them knew about the others.

Items 1-8 kept their numbers and are now `DATA-1` … `DATA-8`. A commit message,
code comment or doc that says "`data-backlog.md` item 5" means **`DATA-5`** in
`backlog.md`, and always will — those IDs are never reused and never renumbered.

Nothing was lost in the move: the open items, the resolved items and the
reasoning that closed them all carried across intact.
